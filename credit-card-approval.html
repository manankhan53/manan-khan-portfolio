Credit card approval prediction

A machine learning classification project predicting credit card approval outcomes, built during my DecodeLabs internship.

Overview

A supervised learning project predicting whether a credit card application would be approved, based on applicant data. Built as part of my Data Science internship at DecodeLabs.

Problem

Credit approval decisions depend on many applicant factors at once. The goal was to build a model that could learn the patterns behind past approval decisions and predict outcomes for new applicants.

Approach

I began with data preprocessing, including handling categorical variables through encoding and preparing numerical features for modeling. Exploratory data analysis was then used to examine feature distributions, relationships, and patterns in the dataset. I split the data into training and test sets and trained two classification models: Logistic Regression and Random Forest. Their performance was evaluated and compared using confusion matrices and accuracy.

What I built

  • Data preprocessing pipeline with categorical encoding and numerical feature scaling
  • Exploratory data analysis using feature distributions, box plots, and correlation analysis
  • Logistic Regression and Random Forest classification models
  • Model evaluation using confusion matrices and accuracy comparison

What I learned

Comparing Logistic Regression and Random Forest side by side showed how different models can produce different results on the same classification problem. The project strengthened my understanding of model evaluation, performance comparison, and choosing a suitable model based on the results rather than relying on assumptions.
