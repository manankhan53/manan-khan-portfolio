Customer segmentation

An unsupervised learning project grouping customers into behavioral segments, built during my DecodeLabs internship.

Role
Developer
Status
Completed
Context
DecodeLabs internship

Overview

An unsupervised learning project that groups customers into distinct segments based on their behavior, without predefined labels — useful for understanding "who are my customers" rather than predicting a single outcome.

Problem

Businesses often treat their customer base as one group, missing meaningful differences in behavior that could inform targeted decisions. The goal was to identify natural groupings within the customer data.

Approach

After preprocessing and standardizing the data, I applied Principal Component Analysis to reduce dimensionality, then used K-Means clustering to group customers. I determined the right number of clusters using the Elbow Method, and validated cluster quality using Silhouette Score.

What I built

  • Data preprocessing and standardization pipeline
  • PCA for dimensionality reduction
  • K-Means clustering with Elbow Method for choosing cluster count
  • Cluster quality evaluation using Silhouette Score
  • Customer segment profiling and visualization

What I learned

Unsupervised learning forces a different kind of validation than classification — there's no ground-truth label to check against, so evaluating whether the clusters actually meant something (via silhouette analysis and profiling) mattered as much as the algorithm itself.
